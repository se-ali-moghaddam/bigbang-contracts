# 🌌 BigBang – Decentralized Lending & Collateral Protocol

**BigBang** is a practice project that explores the fundamentals of decentralized lending using smart contracts. It enables users to deposit crypto assets as collateral and borrow against them, powered by real-time price data from trusted sources and an ERC-20 utility token for protocol interaction.

---

## ✨ Features

- **Decentralized Collateralized Lending**  
  Users can deposit supported tokens as collateral and receive loans based on their collateral value, secured through on-chain smart contracts.

- **ERC-20 Utility Token**  
  The protocol includes its own utility token (ERC-20) which can be used for interacting with the system or potential future governance.

- **Chainlink Data Feeds Integration**  
  Real-time price data for ETH and other supported crypto assets is fetched using **Chainlink Data Feeds**, ensuring accurate and secure collateral valuation.

- **Loan-to-Value (LTV) Calculation & Risk Management**  
  Loans are issued based on dynamic price data, helping maintain system integrity and reduce liquidation risks.

---

## 🧱 Technologies Used

- **Solidity** – Smart contract development  
- **OpenZeppelin** – ERC standards and contract security  
- **Chainlink Data Feeds** – Real-time crypto asset pricing  
- **Hardhat** – Development, testing, and deployment  
- **Web3.js** – Contract interaction in testing
